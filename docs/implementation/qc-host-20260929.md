# QuakeC engine host implementation packet, 2026-09-29

B22 remains incomplete. This packet implements native C host capabilities around
existing QC execution; it does not emulate TypeScript CPU/runtime machinery.
No compilation, tests, game execution, or benchmarks were performed.

## Source scope

New typed host: `include/qa/qc_host.h`, `src/compat/qc_host/{game,call,builtins,entities,physics}.c`
and its private header. Existing VM additions are raw host ABI staging and public
entity spawn/remove in `qc.h`, `memory.c`, and `instance.c`.

New application consumers: `guest_qc.c`, `guest_qc_clients.c`,
`guest_qc_imports.c`, `guest_qc_messages.c`, `guest_qc_checkpoint.c`,
`guest_qc_projection.c`, `guest_qc_qualification.c`, `guest_qc_declared.c`,
`guest_qc_input.c`, and their private headers. Root owns application
composition, shared declarations, map publication, protocol queues, and CMake.

Approved shared console additions: complete metadata capture/restore and
scalar lifetime promotion in `console.h`/`cvars.c`. Existing locale repairs were
preserved. Restore validates the full name/handle set before mutation; promotion
preserves binding owner, and existing removal detaches retiring bindings.
The approved world addition conditionally unbinds a collision callback only when
its actor generation and context still match, allowing safe provider retirement.

## Implemented source paths

- Program-private globals/entities/strings and shared actor/body ownership remain
  in the existing QC VM. Client rows are reserved before dynamic allocation.
- Named/indexed typed source calls validate widths/types, save ABI words 1..27 and
  declared globals, and restore without observing host cleanup as guest stores.
  Callback function indices preserve anonymous/duplicate-name functions.
- ED entity pairs retain source ordering, aliases, declared type conversion,
  string escaping, unknown/editor key handling, spawn exclusions, and source
  missing-class diagnostic/removal. World is private QC edict0; shared geometry
  is the world authority. Missing world spawn is a load failure.
- Engine defaults implement precaches, setmodel, prints, sound/ambient particles,
  cvars/localcmd and shared Q1 movement; existing VM supplies allocation/spatial
  builtins. Profile admission requires real bindings for every required import.
  The application retains source environment defaults including maxclients,
  registered/developer/cheats and time/frag limits; QuakeWorld uses `sv_aim = 2`
  and `sv_phs = 1`. Debug prints honor developer, and unknown cvar_set emits the source
  diagnostic without aborting guest execution.
- Application classic/QW imports implement client visibility, aim, source raw
  message writes/routing/multicast, lightstyles/static models, client commands,
  travel, spawn parms, diagnostics, frag events and info queries.
- Frame component calls StartFrame, client pre/post think, scheduled source
  think, shared entity/pusher physics, and protocol/console flush. Scheduler and
  physics remain shared; private QC deadlines/properties project through typed
  adapters. Guest nextthink stores schedule current source work.
- Client admission preserves full actor generations, invokes SetNewParms,
  ClientConnect/PutClientInServer or QW spectator callbacks, and retains 16 parms.
  Committed travel captures SetChangeParms/serverflags before retirement and
  level reset recreates guest state only after old actor bindings are gone.
- The provider uses the shared native RNG implementation, seeded once at provider
  creation; its complete words, cursors and draw count survive travel and saves.
- Qualified component map initialization retains private VM globals/strings,
  cvars, resources and RNG across travel, stages the new map environment, projects
  existing canonical markers and executes declared initialization once. It does
  not invoke worldspawn or duplicate native authored entities. Unqualified QC
  players currently require that QC also owns ENTITIES; foreign-map primary
  character admission remains guarded until standard marker projection exists.
- World precache uses the selected shared BSP, permitting foreign geometry rather
  than requiring the guest asset VFS to contain that map.
- Raw routed messages retain bytes, recipients, destination/reliability and each
  possible entity-word generation, including QW packed sound references. Root's
  application queue copies these synchronously. Actual wire/demo/local consumer
  integration remains a root dependency. Zero-actor annotations are omitted;
  absent entries mean world/free at write time and must never be re-resolved into
  a later actor. A consumer selects captured annotations only at decoded semantic
  entity positions. Reference storage grows geometrically and survives flushes.
- Engine checkpoint codec stores clients/parms/cache/serverflags, precache order
  and resource digests, geometry identity, lightstyles, routed bytes/references,
  and cvar values/reset/latches/flags plus handles/owners/counters/modified state.
  Decode prepares candidate state before publication. Coupled VM restore already
  commits guest state before host callback; errors are failed-load boundaries.
  Connected client metadata must match the exact restored reserved borrowed row;
  duplicate connected seats/actors are rejected, and saved cvar activity metadata
  is preserved rather than inferred from loading.
- QC collision bindings use private source solid/model/owner/flags with full actor
  generation checks; borrowed actor direct origin/angle/velocity stores commit to
  shared bodies when QC is the selected movement owner.
- VM setorigin/setsize and host setmodel use an optional typed selected movement
  authority lookup, permitting a QC movement owner to control a native character.
  Absent the lookup, existing owned/execution ownership applies; actor generations
  are rechecked after admission.
- Declaration qualification verifies version/runtime/artifact path and content
  digest, resolves original compiled calls/fields, checks ABI types/overlaps,
  and admits supported capabilities only. Unsupported declarations fail before
  live map publication. This is a partial declaration implementation, not B25
  completion.
- Qualified client admission reserves the exact source client slot and retains
  canonical actor generation/seat/spectator/actual CHARACTER selection. It runs
  only declared admit callbacks. Secondary arsenal/effects providers cannot
  invoke stock ClientConnect/PutClientInServer on a foreign character.
- Qualified borrowed field reads/writes project explicit health, inventory,
  body, classname, view-offset and client-flag contracts. Private, constant and
  input fields remain private. Input handlers run at declared command/slice
  phases, publish changed fields or consume controls only after original handler
  entry, and restore nested same-actor input scopes. Native control consumers are
  maintained by the Q2 worker. Borrowed qualified movement retains the existing
  canonical collider instead of replacing it with unspecified stock QC fields.
- Existing canonical map actors become borrowed source markers after authored
  spawn. Native Q3 authored records retain classname as record.definition even
  where generic Q3 traits omit it; that canonical definition is the fallback.
  Filtered/uninstantiated authored rows are not fabricated. Projected identical
  strings share stable engine entries across actors, reducing QW handle usage.
- Qualified client think clears before calling, preserves callback-visible due
  time and QW same-frame repeats; private client frame callbacks follow it.
  Userinfo/disconnect APIs execute declared callbacks while generations are live.
  Root must wire actual userinfo and ordinary disconnect lifecycle consumers.
- Engine checkpoint version 2 includes the declaration digest, once-only
  initialization, actual client CHARACTER ownership and an explicit world-model
  precache flag. A component's first ordinary model is no longer restored as the
  world BSP. Binary32 declaration/clock/count conversions check range before
  narrowing.

## Explicit remaining B22 requirements

1. Rerelease debug drawing, prompt/localization/finale and bot/navigation typed
   imports require concrete application owners. They are not registered as fake
   successes; complete rerelease profile admission currently fails explicitly.
2. Full cross-game combat/inventory/protection/effects/weapon role projection,
   source damage/reaction journal bindings and general callback replacement remain
   required. Current qualification explicitly rejects nonempty callbacks, combat,
   protection, items, pickups, objectives, commands, presentation and client-output
   declarations. Team, score and userinfo field bindings remain unsupported.
   Declared ENTITIES ownership also remains guarded. These are remaining work,
   not removed functionality or acceptance exceptions.
3. Queued console commands/aliases currently reject checkpoint capture instead of
   disappearing. A shared console continuation codec is required for full saves.
4. Wire/demo/local protocol consumers and complete application save registration
   must consume the typed queue and engine/VM checkpoint, not discard it.
5. Root player command dispatch, map client binding and secondary provider map
   initialization consumers now exist in the checkout. Complete userinfo/client
   disconnect/kill handling and qualified guest-Q3 movement input hooks remain
   required. Per-seat qualified QC admission now exists; full declaration parity
   remains open.
6. Direct borrowed mins/maxs/ground entity stores are not yet a complete shared
   body projection contract; engine setsize/setmodel commit final validated bounds.
   Unsupported partial authority must be resolved before general QC acceptance.
7. Shared aim/visibility policy extraction would remove duplication with the
   native Q1 policy; this packet currently uses shared geometry and source ordering
   but implements the small source decisions in its application adapter.

reconfiguration cannot publish an ENTITIES owner that merely runs its initializer

Qualified input now owns a heap scope across the matched before/after pair. It
skips scopes without a declared subscription, leaving private source input
unchanged during unsubscribed movement slices. It
injects declared input fields once, keeps source changes through intervening
callbacks, and restores an outer same-actor command's private input words only
when the nested slice closes. Before failure or actor retirement closes exactly
the newly begun scope and returns failure. A matching after closes its scope on
success or failure; retired actors drain without callbacks or stale writes.
`application_qc_input_abort` drains a successful before whose source processing
fails before after, without inventing an after callback. No matching scope is an
idempotent success. Callers must retain their successful-before provider list and
never abort after attempting after, which already closed its own scope. Capture,
restore, deconstruction and map/roster readiness reject unfinished input. Root
idle admission and native/guest control cleanup consumers are separate owned
integration changes undergoing peer review.
