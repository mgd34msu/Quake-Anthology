# Q3 baseline implementation, 2026-09-29

This packet adds native Q3 and Team Arena ranking report producers. The donor already emits these reports during gameplay; the C family had no equivalent producers. It continues B12 and the Q3 part of B31, without completing either task or BASELINE. The approved unavailable ranking backend remains unchanged.

## Donor and existing C ownership

The behavioral source is `../quake-typescript/src/content/q3/base/game/rankings.ts`. Production event ordering was read in `base/game/weapon.ts`, `base/game/combat.ts`, `base/game/death.ts`, `base/game/item-lifecycle.ts`, `team-arena/client-events.ts`, and `team-arena/team.ts`. No donor or original game source files were copied.

Reports use the existing `qa_ranking_source_report` and `qa_ranking_stat` types in `include/qa/rankings.h`. Gameplay supplies source slots; the application queue resolves them through the shared ranking lifecycle. Strings remain borrowed until the sink returns, so that sink must copy them. The producer uses integer stat keys and small lookup tables instead of string hit identities or duplicated report types.

## Implemented producers and callers

| Event | Native production caller | Behavior |
| --- | --- | --- |
| Fire | `qa_q3_fire_weapon`, `weapons.c` | General and source weapon count; gauntlet fire is counted on damage. |
| Native pickup | `pickup_original`, `items.c` | Weapons, ammo quantities, health quantities, armor quantities, powerups and base holdables. Shared replacement grants bypass these source reports, matching the donor's native admission rule. |
| Holdable use | `q3_use_holdable`, `holdables.c` | Medkit and personal teleporter use. Team Arena's additional holdables have no donor stat keys. |

| Committed damage | Public `qa_q3_ranking_damage` | General and weapon hit/damage/splash counters, friendly fire and gauntlet attacks. Armor loss is taken from the committed mutation journal. |
| Death | Public `qa_q3_ranking_death` | World, suicide and killer/victim reports, with Team Arena means-of-death normalization. |
| Flag and capture | Public `qa_q3_ranking_flag_pickup`, `qa_q3_ranking_capture` | Shared objective owner routes each accepted pickup/capture once. |
| Team name and weapon time | Public typed helpers | Preserve donor report functionality for the application/session and command owners. No donor production callers for these two helpers were established in this packet. |

The new file is `src/gameplay/q3/rankings.c`. Optional `ranking_report` and `ranking_warmup` hooks are declared in `include/qa/game_q3.h`. A missing sink skips reports. The application's shared mode state supplies warmup. These callbacks may inspect, but must not mutate or destroy the Q3 provider.

A rocket shot emits keys `1111020002` and `1111020502`. A 50-point health pickup emits `1111040000`, `1111040001` with value 50, then `1111040300`. These examples follow the donor's key and order. They are source comparisons, not executed examples.

## Checkpoint state

Adjacent hits share one typed tuple containing frame, victim slot, attacker slot and normalized means of death. Identical adjacent tuples suppress additional hit counts while retaining damage totals. It replaces the donor's string identity and does not retain actor pointers. Q3 level reset clears it.

The Q3 typed checkpoint is now version 2. Capture and restore assign the tuple's fields explicitly; no whole-structure serialization was introduced. The application save codec must encode each field explicitly and preserve the version. Existing reviewed world-idle and pending player admission checks remain in place.

## Integration dependencies

The root owns CMake and application routing. Required work outside this packet:

- Register `src/gameplay/q3/rankings.c` in the Q3 library source list.
- Attach the queue sink and warmup hook from shared mode state, preserving the unavailable backend behavior.
- Route committed damage and death once through the public helpers. Calling from every independent Q3 character/effects callback would duplicate reports when those selections belong to different providers. Damage reporting precedes death reporting.
- Route shared objective pickup/capture events through their public helpers. Q3 team items already return through the shared objective hook, so the native item caller does not also count them.
- Supply an `entity_number` projection that maps canonical players to ranking client slots, including foreign characters. Q3's standalone fallback only projects owner-matched source actors; other actors map to world slot 1022.
- Extend the explicit application checkpoint codec for the version-2 tuple.
