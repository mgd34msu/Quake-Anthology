# Bot source admission and retained Q3 rounds

The source-stage producer now uses the published roster's actual map provider.
It runs only during that provider's genuine admitted source frame. It receives
the frame's source time and elapsed interval, verifies the actual host boundary,
and queues commands through the ordinary retained actor admission owner. The
selected movement source drains those commands on its own admission. Accepted
command sequences include queued commands, so a later producer cannot reuse an
unapplied sequence. Foreign command conversion uses the generated Q3 byte axes,
source angle words, dialect scales, and buttons from `selectedQ3Command`.
Requested Q1/Q2 weapons resolve to the actual selected arsenal's item and owner
without selecting during generation. The retained command owner carries that
intent and selects it at the genuine command phase.

The TypeScript source contracts are `SimulationRuntime`'s bot service frame
calls, `ApplicationBots.beginRoundRestart`, `bindRestartedRound`,
`reconnectRestartedClient`, and `resumeRoundBots`, and
`SourceBotDirector`'s corresponding AI lifecycle. The library survives; the
round AI, client actor bindings, command sequences, and mutable navigation
belong to a fresh round. Static map goals and immutable navigation graphs retain
their existing owners. `GoalLibrary.rebindWorld` clears source actor goal
identities while retaining map metadata and its source goal allocator.

`application_bots_round` copies the real admitted source client rows and bot
settings before mutation. The original requested character path, unclamped
skill, and full admission name are now owned by each native bot continuation.
They are retained through ordinary resets and deep copied by checkpoints.
Population schema 2 includes those values. Application bot schema 2 includes
the actual bot library client identity independently of canonical actor slots.
Both readers reject old schemas and incomplete data.

Beginning a round destroys the native per-round population and preserves the
library. The guest GAME owns its original `BotAIShutdown(true)` callbacks.
Binding installs fresh mutable navigation runtimes over the retained graphs,
retires old source goal and observation identities, and constructs fresh native
round AI. Reconnection validates the actual newly admitted source actor and
reuses the preserved bot library client. It requires the three completed
100 millisecond source settlement frames; resumption requires the fourth and
completion or actual rejection of every preserved bot. Partial failure retains
the remaining owner storage for destruction and prevents ordinary bot frames.
Checkpoint capture rejects prepared or incomplete round cuts.

This packet does not establish the complete Q3 restart caller. Source player,
transport, reliable command, GAME reset, presentation, and ranking owners must
complete their corresponding cut. The existing native C bot AI still lacks the
oracle's complete last team goal session and exit chat behavior. Those remain
open source obligations; old actor references and old AI decisions are not
carried as a substitute.

Verification is source inspection and a whitespace check only. No build,
compiler, test, game, parser, generator, or benchmark has run for this packet.
