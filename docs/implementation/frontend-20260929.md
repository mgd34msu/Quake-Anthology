## Source behavior and callers

The behavioral references were the donor's getting-started/playing documentation and `src/app/bootstrap` startup, input, menu-font, console and frame ownership; native library/mod/account/HUD code and public service headers were read before writing these callers. No donor or original game source file was copied.

## Review limits and remaining baseline work

Only source reads, searches, diffs, whitespace checks and source hashes were used. `git diff --check` passed for the owned paths. No configure, compiler, parser, test, executable, game, benchmark or sanitizer was run. These are source implementation observations, not runtime parity claims.

The packet still depends on the actual parent/peer application presentation/context/visual/weapon producers and tools/network/native-Q2 implementations and build inventories. Remote host/client signon and full state admission are not claimed by declaring options or invoking networking hooks. Qualified source companion-role admission must supply actual ready UI/cgame roles; frontend callbacks do not guess companion paths.

B32 still needs complete source-family HUD/stat/layout consumers, authored console/menu typography and localization/fallback selection, accessibility and categorized settings/input/controller workflows, save/load/autosave menus and continuation, match/bot/lobby/browser administration, online chat routing, source/native campaign cinematics and all other donor-required workflows. Current settings expose real cvars through a generic editor. Current chat broadcasts locally; targeted remote chat reports unavailable. Ranking account services preserve actual unavailable states.

Native visual continuation is incomplete for native Q3 tagged player parts/animation/view weapons and authored effect/skin/attachment selection, and qualified guest appearance observations. Foreign source asset selection must resolve the actual selected provider; a source's default registry alone does not prove every mixed-game path. Native actor model cache diagnostics also need inclusion beside source handle diagnostics. The default menu Unicode font currently requires the configured font directory/file (Linux DejaVu default); this is not a portable delivery-font layout. Per-family original font assets remain required.

The native-Q2 source platform adapter is being authored separately and must retain its own actual guest lease through source teardown. Persistence safe publication and saved frontend owner schemas remain pending. B34 packaging/distribution layout and complete subsystem caller coverage remain parent-owned open work. This packet requests independent source review through the parent; it does not mark B32/B34 or BASELINE complete.
