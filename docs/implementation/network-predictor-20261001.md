# Native remote prediction bindings

The Network-owned predictor copies the actual selected player's constructor
configuration before any wire or physical command. Its live source reads the
real compiled CLIENT cache, retained decoded prediction scene, private map
geometry, selected role configuration and native command acknowledgement.
Cached prediction fields are compared individually, including float bits;
unrelated view-cache changes do not expire this projection.

The previous presentation clock comes from the real runtime prepare latch.
Physical event receipts use frontend wall time. Raw signed Q3 command time
remains separate. The independent source builder consumes the same physical
sample as selected movement, appends one native command and verifies its exact
retained words before pairing it with selected prediction.

Initial association requires the actual appended zero command or a genuinely
cleared positive map-restart ring head. A restart reached at command count zero
waits for the real later append. Restore retains literal QRPD bytes until native
service and snapshot owners exist, then imports the saved cold constructor
configuration before allocating the copied predictor.

Source-only engineering remains in progress. Physical frame migration, actual
native Session construction/media, late aggregate import, fresh world-travel
constructor ownership and original external CG cache/profile producers are
separate necessary integration work. No runtime execution or full networking
acceptance is claimed.
