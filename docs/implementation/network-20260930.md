## Production call chain

`frontend_network_create` resolves `--connect` for `q3-68`, checks the qualified selected source and one presentation seat, retains the complete local launch digest, and starts `qa_q3_client_admission`. Resends use the existing original challenge/connect codec through the shared runtime transport. The runtime's connectionless callback consumes challenge/connect responses and records pending attachment. `client_drain` attaches the source peer only after the receive callback returns.

`qa_network_attach_q3_client` binds the actual original channel to the connection table. The runtime is the sole UDP receiver. Source channel ordering, fragment reassembly, XOR, reliable acknowledgement, server command history, baseline/delta decoding and snapshot history remain in `qa_q3_client_peer`. Successful signon and snapshots advance the shared connection phases. Timeout and teardown close the peer and its histories with the transport owner.

The frontend's external `qa_q3_host_client_services` expose the peer's retained gamestate, bounded snapshots, server commands and usercmds to the selected cgame. They can be installed during provider preparation before the network owner exists because the service context is the retained frontend. The cgame's source prediction restores the complete incoming playerstate and replays retained source usercmds through its ordinary imports. This path does not apply remote commands to local GAME state or claim the separate native mixed prediction checkpoint hooks are complete.

Server command execution uses the existing peer implementation, including continued configstrings, systeminfo, map restart and disconnect handling. The application adapter copies decoded command arguments into the selected cgame's actual argument owner. New gamestate shuts down that cgame before reinitialization. Source map restart clears the source command ring and resets the client clock while preserving source command numbering. Generated commands retain cgame weapon/sensitivity and source server time. The builder initializes view angles from incoming viewangles minus deltaAngles and preserves subsequent local input.
