## Changes in the first patch

- `arsenal.c` admits physical classic QC NQ clients to the actual source actor
  pass using the real component `command_actor` predicate, alongside native Q1.
- `control_frame.c` recognizes that physical NQ pass independently of canonical
  Character ownership. A transient full actor/provider/frame completion marker
  prevents a second canonical visit from running QC `beforeActor` again after
  consuming the retained turn. The marker is absent from saved state, makes the
  input owner busy, and clears at release, abort, and actual command completion.
- `control.c` selects the qualified physical primary NQ source for source
  callbacks during nonraw retained NQ commands. Canonical execution remains the
  fallback when the actor has no qualified physical NQ source membership.
- `arsenal_guest.c` computes the original QVM callback interval with signed
  64-bit subtraction before clamping the outer interval to 0..1000 or the slice
  to 1..200. Original PM timer arithmetic was not changed.
- `arsenal_guest.c` projects only the attack control from foreign selected
  movement into the original Q3 usercmd buttons. Raw holdable and other controls
  outside that movement dialect survive. Source input hooks still own genuine
  changes to the full source command.
- `control_frame.c/.h` retain a separate `qw_receipt_time_ns` on true raw QW
  input. Input/group `source_time_ns` keeps its admission meaning; the last QW
  command observer returns the receipt timestamp. Native Q1 uses its real
  gameplay clock. QC uses the qualified reader supplied by the QC owner.
  Saved inputs encode the receipt separately, require zero for other domains,
  and reject receipts later than actual admission.

The completion marker is separate from `frame_owned`, which is also set during
PREPARE and cannot establish that a physical turn has completed.

[Quake Anthology TS](https://github.com/mgd34msu/Quake-Anthology-TS).

`src/compat/qvm/game-equipment-movement.ts` clears holdable only when a genuine
equipment frame owns that input, with conditional restoration afterward.
