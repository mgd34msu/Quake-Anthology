Map loading copies the active launch draft and replaces only the requested world fields before calling the existing transaction. The publication retains and commits the BSP resource, collision geometry, stable world, provider roster, and actor retirement. The map packet creates no second world or geometry owner. Preparation can retain inventory and intern strings, but does not run guest continuation callbacks or mutate live entities.

Native Q1 spawn selection uses the existing ordered campaign selector, including five-second deferred spawn admission. Native Q2 character admission calls source connect, admit, and spawn; authored `$spawn` is passed both to the map context and player rules. Native Q3 admission uses selected character, arsenal, effects, combat, and equipment flags. Q3 authored spawnpoints come from the native decoder after source filtering; shared modes classify authored points and own their actual team identities and selection rules.

Travel captures one shared combat state and one shared inventory array per player. Q2 capture transfers its inventory array rather than copying it again. Typed native continuation captures maximum health, selected weapon and MG3 progression as appropriate; new actors receive no old actor references. The shared native carry predicate is applied independently to the selected character's health/maximum and selected arsenal's equipment/weapon. Q1 base temporary carry items are the six source items, rather than every key/powerup namespace. Native Q1 addon start/world-type/horde reset policies and final-boss next-level health are applied during admission. Q2 unit key clearing is cooperative-only; broad rerelease powers/flags reset is left to the actual authored intermission trigger.

QC and Q3 guest client admissions call the real guest adapters. A continued guest is recognized by its prior selected provider owner and exact implementation/configuration identity; switching guest instances initializes new source client parameters. Q3 connect receives the corresponding first-time flag. Guest characters choose their own spawn instead of consuming a second native spawn selection. The selected movement owns the final standing hull.

Authored map/gamemap/changelevel commands and native Q1/Q2 transition callbacks create typed pending travel. The application caller commits map travel only at an idle authority boundary. Media travel requires an explicit presentation completion acknowledgment. `nextserver` retains the remaining source chain instead of pretending a cinematic/demo has been played.
