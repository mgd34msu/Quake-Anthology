# Native Q3 source pool continuation

The native GAME owns 1,024 physical source rows and 64 stable client records. Client bindings retain full canonical actor generations independently of selected character ownership. Ordinary map initialization creates the source world row and eight persistent body queue rows before authored allocation. All native dynamic constructors use the source allocator; filtered and discarded authored entities also allocate and free through its source reuse policy. Body copies reuse the initialized queue actors.

Typed and portable native continuation version 8 retain the physical extent, bindings, free times, source numbers, source classnames and activation, flags, disconnected client records, accepted command words, native player event rings, retained physical enemy references and source temporary entities. Restoring a map candidate binds its services through `qa_q3_maps_bind_restore`; actor creation and source callbacks belong to ordinary map initialization. Current client inventory leases retain their original shared-store ownership.

Native ClientConnect clears its source client fields while preserving component membership, and bot admission activates the actual source row before bot connect. ClientBegin performs the modeled source player-state reset before spawn. Spawn initializes source command time and clientNum, and actual movement or ClientThink completion advances command time. Disconnect has a real item/persistent-item drop helper and a separate final unlink/deactivation mutation for the application owner to order around mode and log producers. Teleport events allocate physical temporary entities with source lifetime. The source settings callback runs after the actual frame ENTRY clock write and before map/entity processing; cached finite source rule values can reach the existing damage, weapons and item consumers without construction range restrictions. Bot random requests use the native GAME's existing RNG.

Behavioral references are Quake Anthology TS's `content/q3/base/game/entities.ts`, `state.ts`, `team-arena/client-admission.ts` and `client-spawn.ts`, together with original `g_utils.c` and `g_client.c`.

This packet requires independent source review and application integration. Complete native protocol player/entity words, source link visibility, all source team-state counters, cached settings, shader remaps and their producer hooks remain separate work. No build, compiler, test, executable, parser, generator, sanitizer or benchmark was run.
