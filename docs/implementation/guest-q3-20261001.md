## Original command continuation

The application-side client owns the raw BCS buffer and its byte length. Removed
the obsolete active/index fields from `guest_q3_private.h` and their serialization
and strict numeric-prefix validator from `guest_q3_save.c`. Nested `QAG3ST` is now
version 3. It preserves presence, length up to 8191, bytes and their terminating
NUL. Absent buffers require zero length. Present empty buffers, unfinished raw
prefixes and buffers retained after completion remain valid.

Read the complete live parser in `guest_q3_clients.c` and complete enclosing
private/provider codec in `guest_q3_save.c`. The parser already accepted exact
bcs0/bcs1/bcs2, missing argv fragments, arbitrary start-index spelling, native
integer conversion at actual cs dispatch, and argv2-onward joining. Completed
bcs2 now goes back through command dispatch. This also handles a constructor-empty
continuation whose text resolves to disconnect or another BCS command.
After successful CS dispatch it restores tokenization of the actual command
text, as the SDK and TypeScript donor do. A synchronous SystemInfo receiver can
reenter GetServerCommand and replace role arguments; the outer command therefore
restores its arguments before later dispatch and its caller reads them.

## Explicit CGAME timing authority

`qa_q3_host_options` now carries optional `client_time_cvars` and
`client_time_owner`. An actual local CGAME constructor can set the construction
request `client_time_from_game`. `q3g_client_bind` resolves that request against
the actual native GAME lease or original GAME host and clears it before creating
the host. An explicit local pair must match that exact GAME registry and owner.
Omitted options stay absent. A standalone or remote factory supplies its own
actual optional pair. GAME hosts cannot install client timing authority.

Both host and application borrowed context views return the concrete pair.
The local application view checks it against its actual source registry and
source owner. It still preserves the actual frontend lifetime pointer, service
owner generation, receiver console/cvars/command context, physical source client,
full GAME source frame and signed milliseconds. Pre-Init SystemInfo retains its
real host context; UI continues to use its real/frontend clock independently.

The host service fingerprint `QAG3SV` is now version 2. It includes optional
presence, alias with receiver cvars, logical owner and dialect. Full provider
restore recaptures this fingerprint after actual service reconstruction.
