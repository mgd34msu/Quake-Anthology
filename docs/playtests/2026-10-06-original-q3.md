# Original Q3 renderer and restart checks

The testing executable built from `3225d70a` renders the retail `q3dm1` world
correctly in the observed starting view on CPU and GL. The previous horizontal
texture corruption is gone: walls, floor and rust trim have their expected
textures. Stock HUD glyphs remain visible, without the duplicate builtin HUD.
Both public quit commands exited normally.

The lightmapped fast path now pairs normalized base and lightmap texture units
with the corresponding normalized texture-coordinate banks. This follows Q3's
`tr_shader.c` bundle normalization and `tr_shade.c` lightmapped submission.
It does not change generic shader-stage coordinate generation.

The testing executable built from `92acfd4a` also passes an actual public
`/map_restart 0` on CPU and GL. Each runtime log records two GAME initializations,
player entry after the restart and normal final shutdown. The restored world,
weapon and stock HUD were inspected in screenshots. Each process exited zero;
the installed executable remained unchanged.

The queued restart runs inside the existing frame preparation cut, where the
round-event consumer has its retained driver. The public command previously
reached that consumer between frame preparations and failed.

These checks use `--original`, installed retail content and real SDL keyboard
input. No debugger was attached to the successful visual or restart runs.
They establish the observed material rendering, restart and shutdown behavior;
they are not frame-time measurements or complete Q3 campaign qualification.
