# Q3 link bounds and visibility continuation

The guest record owner computes source rotated-brush bounds and epsilon before
linking. qa_world_link_bounds now admits that explicit snapshot through the
same authoritative body read, count increment, spatial publication and
notification path as ordinary links. It copies and validates supplied bounds
before callbacks and bypasses only the optional global bounds hook.

The shared leaf query now returns Q3 last_leaf independently of output capacity.
It records the last visited leaf whose cluster is not -1, including leaves after
overflow, with source default zero. Root compared the traversal with donor
collision/q3/topology.ts. The Q3 host owner independently reviewed both changes;
no defect was found in this bounded pass. Its foreign-map path keeps the donor's
separate sorting of captured leaves.

The concrete Q3 host and application consumers remain under implementation.
No engine compilation or execution was performed.
