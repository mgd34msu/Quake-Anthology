# Q2 mover observation review

The bot owner read the complete new Q2 mover observation and the affected public
view, then compared its detached facts with native train destination/use paths,
platform and plat2 spawn/operate/finished paths, door/button motion/use, shared
target lookup, scratch snapshot reservation and Q2 source invocation/frame-entry
admission. This is bounded source inspection; no build, compiler, parser, test,
executable, game or benchmark was run.

The Q2 owner found and repaired a branch-lock defect during self-review: an
unselected keyed reverse branch could mark an unrelated parallel button path
locked. The reviewer reread the correction. The queue reserves one root plus
the actor snapshot and retains full actor parent identities in its second
snapshot buffer. Each relay is removed from the search pool when enqueued,
bounding queue growth and cycles. Only the chosen button's parent path contributes
key lock state. Scratch borrows release on all observed failures and success.

The train observer uses the actual retained destination when it exists. Future
unique-target lookup draws no random number; ambiguity terminates the known
route prefix. Native classic/rerelease bounds offsets and edition flags match
the live train destination helper. Team child offsets retain the queried brush's
frame. Platform endpoints, phases and activation admission come from source
continuations. Queries run inside `qa_q2_run_actor`; the previously accepted
frame guard prevents callback-driven actor storage recycling.

No further confirmed defect was found in these inspected paths. Foreign target
activation ownership, complete train gameplay, angular brush sweep and recipient
specific key planning are not accepted by this review.
