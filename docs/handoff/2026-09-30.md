## 5. Architecture invariants that have repeatedly mattered

### Authority and identity

- Keep one canonical actor registry/world/session. Every retained actor reference must preserve full registry/slot/generation identity.
- A physical source client/edict number is not a canonical actor slot and not the selected Character's slot.
- Distinguish actual ENTITIES GAME, canonical execution owner, selected movement, Character/Arsenal/Equipment, and chosen primary rule provider. Source callbacks and public protocol records need their real physical owner.
- Native Q3 GAME owns fixed 64 client-source records; configured max_clients is a separate constructor/admission constraint. Fixed inactive client pointers/PS fields may be observed where the donor does so without fabricating live actors.
- Native Q3 source sess/count/sorted/follow/TEAM/match state belongs to GAME, not a generic selected-mode mirror. Valid generic chosen-mode state for nonnative worlds still exists and must not be blanket-deleted.
- A source record whose actor is detached must follow the donor's real null-body behavior. Native TS uses authentic ZERO_BODY, not a stale canonical-body mirror. Retained model/contents/owner/link fields have their own source lifetimes.

### Time, scheduling, effects, and numerical domains

- Preserve true source clocks, source ENTRY versus completed EXIT time, callback deadlines, command time, and UI frontend real time. Do not substitute wall time or canonical movement time.
- Preserve RNG owner/draw order, callback order, source numeric conversions, immediate mutation visibility, link/currentOrigin versus PS/body authority, pending callbacks, and safe publication.
- Native source usercmd duration is cmd.serverTime minus actual PS commandTime, clamped at the donor stage. The outer host-frame elapsed value is a different domain.
- Original QVM input application interval uses mathematical signed-word difference at its declared hook; original PM timer arithmetic remains a separate domain.
- Source Think deadlines in relevant Q3 paths round to float before the actual positive/due comparison. Source timestamps/counters need their declared float32 or int32 domains.
- Required source effects must occur through real installed services. Do not replace LOG with print/MESSAGE, state with event history, or missing producers with empty owners/no-ops.

### Lifetime and continuation

- Preserve physical leases through actual source Shutdown and module/image destructors. A callback may retire an actor or owner; requalify real identity after effectful calls.
- Failed teardown retains the real owner and its necessary contexts for retry. Clear consumed borrowed aliases at the proper last-release boundary, not storage still needed by retained children.
- Candidate restore is detached. Do not use ordinary live creation, VFS registration/load, source callbacks, event replay, network sends, or procedural asset registration to reconstruct a private owner.
- Serialize true allocation extents, physical order, generations, aliases, clocks, allocator/free state, private raw buffers, pending queues, and source mutable values. Count-derived reconstruction is not universally equivalent.
- Private malloc strings must remain private text; qa_source_save_text can intern canonical session strings and is wrong for several private frontend names.
- Pure qualification must precede no-fail adoption/publication. One root must have one destructor authority; borrowed map-world and owned preview roles are distinct.
- FOLLOW native TS copy semantics retain the follower's canonical-backed origin, velocity, health, armor, weapons, and ammunition while copying genuine source-backed PS fields. Do not blindly replace it with external SDK's whole-copy behavior.
